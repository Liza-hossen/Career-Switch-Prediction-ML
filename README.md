Career Switch Prediction using Machine Learning

📌 Overview

This project explores Career Switch Prediction using Machine Learning techniques. It focuses on data preprocessing, exploratory data analysis (EDA), feature engineering, supervised classification, and unsupervised clustering to analyze career-switching patterns.

🎯 Objectives

Analyze the dataset and understand its features.

Handle missing values and preprocess categorical data.

Perform exploratory data analysis and data visualization.

Train and compare different machine learning classification models.

Explore clustering techniques to identify patterns in the data.

Evaluate model performance using multiple metrics.

🛠️ Technologies Used

Language: Python

Environment: Google Colab / Jupyter Notebook

Libraries: Pandas, Matplotlib, Seaborn, Scikit-learn

Machine Learning: K-Nearest Neighbors (KNN), Logistic Regression, Neural Network (MLP), Decision Tree, K-Means Clustering

Evaluation Metrics: Accuracy, Precision, Recall, Confusion Matrix, ROC Curve, AUC
